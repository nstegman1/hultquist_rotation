# Hultquist Rotation Scripts

This is the compiled code I made for my Hultquist lab rotation project.

## Description

This project consisted of three main parts:
* RNAseq Pipeline
* APA Analysis
* Data Visualization
* Creation of shared gene lists

The RNAseq and APA analyses were performed on Quest; however, the data visualization and creation of shared gene lists were done locally on my Mac machine.
